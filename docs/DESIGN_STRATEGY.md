# Direção do portfólio

O portfólio usa uma linguagem editorial: tipografia grande, espaço livre, linhas finas, notas curtas e imagens que pertencem aos próprios projetos. A intenção é que a página pareça uma seleção de trabalho, não uma interface de software.

O ponto de partida é simples: mostrar o problema, a decisão tomada e a evidência que pode ser vista. Por isso, cada case usa o mesmo caminho de leitura, mas não tenta esconder limites de infraestrutura, acesso ou confidencialidade.

O site é estático por escolha. O conteúdo é legível sem JavaScript; o script só apoia menu, busca e filtros. A paleta é reduzida para manter foco no material de cada projeto, com laranja para orientação e cor específica quando o próprio case pede destaque.
