Cadastro e consulta sem editar a planilha diretamente

A empresa já mantinha uma planilha oficial para registrar os aplicativos, mas editar e consultar os dados diretamente não era prático para todo mundo. Criei um aplicativo Windows para deixar essas tarefas mais simples, mantendo a planilha como fonte oficial.

Uma interface para o registro

Atualizar e consultar informações sem depender de abrir e editar a planilha à mão.

ConsultarAtualizarPlanilha oficial
01

O problema

A planilha centralizava as informações, mas o formato dificultava a consulta e a manutenção por pessoas com necessidades diferentes.

02

O que desenvolvi

Construí uma aplicação Windows para cadastrar, editar e consultar informações, mantendo a planilha oficial como fonte dos registros.

03

Como é usada

As pessoas que precisam consultar os aplicativos usam a interface para encontrar as informações; quem mantém o registro faz as atualizações pelo aplicativo.

04

O que demonstra

Uma ferramenta simples pode tornar um registro oficial mais prático sem mudar a forma como a empresa guarda os dados.

Tecnologias

Python · Tkinter · Excel · openpyxl · aplicativo Windows.

Privacidade

A planilha real permanece na empresa. Este case explica o fluxo sem expor o arquivo ou as informações nele contidas.
