## Executar e validar

    npm ci
    npm run build
    npm run preview

A fonte da versão pública é site-release/. O build confere o manifesto de hashes e gera dist/. Os scripts históricos ficam preservados para referência.

Com as dependências Python de requirements-verify.txt e requirements-resumes.txt e o Chrome instalado:

    npm run resumes:verify
    npm run test:full

O [pipeline do GitHub Pages](https://github.com/Mayconxzdev/mayconxzdev.github.io/actions/workflows/pages.yml) valida, publica e confere os hashes dos arquivos acessíveis na internet.

## Escopo

O conteúdo público usa dados fictícios, exemplos e mídias selecionadas. Não inclui bancos, credenciais, documentos originais ou dados operacionais privados. Coautoria, limites de adoção e estágio das soluções são tratados nos respectivos cases.
