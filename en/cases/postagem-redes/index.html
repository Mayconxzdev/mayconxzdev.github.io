01

Context and problem

Content scattered across folders and spreadsheets, informal approvals and duplication risk across networks.

02

What I did

Visual portal, workflows, API contracts, assistive AI, queues, idempotency, ledger, retry, testing and documentation.

03

How I built it

Three separate workflows for interface, actions and media; OpenAI → Gemini → Ollama fallback; dispatchId and reservation before external calls.

04

What is demonstrated

  • Multi-image Facebook publication confirmed.
  • Instagram carousel validated; later tunnel limitation documented.
  • 58 nodes in the public actions workflow.

What this case does not show

X remains blocked by account credit and LinkedIn depends on Page access; neither is presented as complete.

If the operation grew

I would use stable media hosting, independent per-network adapters, full OAuth lifecycle management, confirmation webhooks and destination-level observability.

Public evidence contains no credentials, personal data or sensitive internal information.
