The problem I wanted to solve

I had jobs coming from multiple sources, duplicates, incomplete descriptions and too much time spent deciding whether an opportunity actually matched the direction I wanted. I also wanted resume claims to be tied to evidence instead of living in an isolated document.

What I built

  • multi-source discovery and deduplication;
  • job import by URL, text or file;
  • Career Goal to separate technical fit from career direction;
  • versioned profile, facts, projects and evidence;
  • Resume Router/Fitness;
  • application timeline;
  • browser assistant with manual final submission.

AI is reinforcement, not a dependency

The core does not depend on generative AI. Local matching, career rules, deduplication and safeguards continue working without a provider. Ollama, LM Studio, Qdrant, SearXNG and other components can add capability without becoming mandatory infrastructure.

One rule I kept

The system can prepare but cannot invent experience or submit an application on its own. CAPTCHA, site terms and final submission remain human. EvidenceGuard blocks sensitive claims that do not have enough support.

Architecture at a glance

Sources / URL / File → normalization → deduplication → Career Goal → matching → EvidenceGuard → Resume Router → application → browser assistant → manual submission

Stack: FastAPI · Python · SQLAlchemy · SQLite/WAL/FTS5 · React · TypeScript · Vite · Tauri v2/Rust · MV3 extension

If you want to review the code

The public repository is intentionally smaller. Start with examples/career_goal.py, examples/evidence_guard.py, examples/resume_router.py and the architecture/testing docs. The examples are sanitized excerpts and do not pretend to be a standalone package.

What I would do differently today

I would separate mandatory core, optional capabilities and external integrations from day one. That separation made later versions more predictable. I would also have created Career Goal earlier: a technically compatible role is not automatically worth prioritizing.
