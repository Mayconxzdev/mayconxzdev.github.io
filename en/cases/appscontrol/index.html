Application Control

Update and search without editing the spreadsheet directly

The company already had an official spreadsheet for its application register, but editing and searching it directly was not practical for everyone. I built a Windows app to make those tasks simpler while keeping the spreadsheet as the official source.

An interface for the register

Update and look up information without opening and editing the spreadsheet by hand.

SearchUpdateOfficial register
01

The problem

The spreadsheet brought the information together, but its format made lookup and maintenance harder for people with different needs.

02

What I built

I built a Windows application for creating, editing and looking up entries, while keeping the official spreadsheet as the source of records.

03

How it is used

People who need to check applications use the interface to find information; those maintaining the register make updates through the app.

04

What it shows

A focused tool can make an official register easier to use without changing how the company keeps its data.

Technology

Python · Tkinter · Excel · openpyxl · Windows application.

Privacy

The real spreadsheet stays with the company. This case explains the workflow without exposing the file or its information.
